# bizwap

biz sim for wap content

เอกสารอธิบายการใช้ Media — แผนการตลาด 8 เดือนสำหรับแพลตฟอร์มดูดวงและไพ่ทาโรต์
พร้อมเครื่องคำนวณ unit economics และงบโฆษณาแบบปรับค่าได้

## โครงสร้าง

```
index.html        หน้าเอกสารแผนการตลาด
sim/sim.html      Investment Decision Simulator
sim-single.html   sim ทั้งชุดรวมเป็นไฟล์เดียว สร้างด้วย sim/build-single.py
css/style.css     สไตล์ทั้งหมด light/dark theme
js/app.js         theme toggle, modal, เครื่องคำนวณ
bin/              ไฟล์อ้างอิงระหว่างทำงาน
info.txt          โจทย์ตั้งต้นจากลูกค้า
```

## รันดู

ไม่มี build step เปิดไฟล์ได้ตรง ๆ

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

เปิดไฟล์จากดิสก์ตรง ๆ ก็ได้ แต่ควรผ่าน HTTP เพื่อให้ฟอนต์และ path ทำงานเหมือนบน production

## หมายเหตุเรื่องตัวเลข

ตัวเลขทั้งหมดในเอกสารเป็น **สมมติฐานตั้งต้น** ยังไม่มีบริการจริงให้วัดผล
ตัวที่ต้องแทนด้วยข้อมูลจริงเร็วที่สุดหลังเปิดบริการ:

- อายุสมาชิกเฉลี่ย (ตอนนี้เดา 60 วัน) — กระทบเพดาน CPA มากที่สุด
- Collection Rate จริงของ AIS
- สัดส่วนคนเลือกแพ็กเกจรายครั้ง / รายวัน / รายเดือน
- เกณฑ์ CPM / CTR / CVR / CPA ของตลาดไทย — ปัจจุบันเป็นกรอบอ้างอิง ไม่ใช่ข้อมูลจากบัญชีโฆษณาเรา
