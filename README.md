# bizwap

biz sim for wap content

สองหน้า สองหน้าที่ ใช้สมมติฐานชุดเดียวกัน

| | ตอบคำถาม | คนอ่าน |
|---|---|---|
| **หน้าแผน** `/` | จะทำอะไร เดือนไหน ทำไม | ลูกค้า + ทีม |
| **Simulator** `/sim/sim` | ใช้เงินเท่าไร ได้คืนเมื่อไร | นักลงทุน |

## โครงสร้าง

```
index.html         หน้าแผนการตลาด 8 เดือน
css/style.css      สไตล์หน้าแผน · light/dark · print report
js/app.js          theme toggle, modal, เครื่องคำนวณในหน้าแผน

sim/sim.html       Investment Decision Simulator
sim/css/app.css    สไตล์ · light/dark · print report + โหมดพิมพ์ใบสรุปค่าใช้จ่าย
sim/js/model.js    ตรรกะคำนวณล้วน ไม่แตะ DOM เลย
sim/js/ui.js       อ่านผลจาก model แล้ววาดหน้า ไม่มีสูตรธุรกิจอยู่ในนี้
sim/build-single.py  รวม sim ทั้งชุดเป็นไฟล์เดียว

sim-single.html    sim ทั้งชุดในไฟล์เดียว สำหรับสำรองหรือส่งต่อ
_redirects         /v2/* -> /sim/sim (ลิงก์เก่าที่แจกไปแล้ว)
bin/               ไฟล์อ้างอิงระหว่างทำงาน
info.txt           โจทย์ตั้งต้นจากลูกค้า
```

**แหล่งความจริงเดียวคือ `sim/js/model.js`** — หน้าแผนไม่เขียนตัวเลขที่คำนวณได้ลงไปตรง ๆ
ถ้าต้องอ้างตัวเลขที่เปลี่ยนตามสมมติฐาน ให้ลิงก์ไปที่ Simulator แทน

## รันดู

ไม่มี build step ยกเว้นตอนสร้างไฟล์รวม

```bash
python3 -m http.server 8000     # แล้วเปิด http://localhost:8000
python3 sim/build-single.py     # -> sim-single.html
```

เปิดไฟล์จากดิสก์ตรง ๆ ก็ได้ แต่ควรผ่าน HTTP เพื่อให้ฟอนต์และ path ทำงานเหมือนบน production

## สิ่งที่ Simulator แยกให้ชัด

| | |
|---|---|
| Gross vs Net Revenue | Gross คือยอดเรียกเก็บ · Net คือยอดหลังหักการเก็บเงินไม่ผ่านและส่วนแบ่งทุกฝ่าย |
| Gross vs Net LTV | คิดงบ ADS จาก Net เท่านั้น |
| Paid CPA vs Blended CAC | Paid CPA ใช้ตัดสินระดับชุดโฆษณา · Blended CAC ใช้ตัดสินธุรกิจทั้งก้อน |
| ROAS vs Contribution | ROAS ไม่หัก Content และต้นทุนคงที่ จึงไม่ใช่กำไร |
| Contribution vs Cash Flow | Contribution ไม่หักต้นทุนคงที่ · Cash Flow หัก |
| Operating Break-even vs Payback | เดือนที่เลี้ยงตัวเองได้ ≠ เดือนที่ได้เงินลงทุนคืน |

## เอกสารที่พิมพ์ได้

- **หน้าแผน** → ปุ่ม PDF ได้รายงานหน้าปก + ภาพรวม + ต้นทุน + สมมติฐาน
- **Simulator** → ปุ่ม PDF ได้ทั้งโมเดล · ปุ่มในหัวข้อ Budget ได้ **ใบสรุปค่าใช้จ่ายหน้าเดียว** สำหรับอนุมัติงบ

## แชร์ชุดสมมติฐาน

เลื่อนค่าใน Simulator แล้วกด **คัดลอกลิงก์** — ทั้งชุดถูกเก็บไว้ใน `#` ของ URL
คนที่เปิดลิงก์จะเห็นค่าเดียวกันทุกตัว

## หมายเหตุเรื่องตัวเลข

ตัวเลขทั้งหมดเป็น **สมมติฐานตั้งต้น** ยังไม่มีบริการจริงให้วัดผล
ค่าตั้งต้นปัจจุบันคือชุด **Viable Path** ซึ่งเป็นเป้าหมายที่ต้องทำให้ได้ ไม่ใช่การพยากรณ์
กด **Base Case** เพื่อดูว่าชุดสมมติฐานเดิมไม่ถึงจุดคืนทุน

ตัวที่ต้องแทนด้วยข้อมูลจริงเร็วที่สุดหลังเปิดบริการ เรียงตามผลกระทบที่วัดได้:

1. **Customer Lifetime** — ยังเดาล้วน กระทบทุกอย่างตั้งแต่ LTV ถึงจุดคืนทุน
2. **Organic Customers ต่อเดือน** — ตัวที่ขยับ Contribution แรงที่สุดในโมเดลปัจจุบัน
3. **Collection Rate** — วัดจากรายงานการเรียกเก็บจริงของ AIS
4. **Conversion Rate** — วัดจากหน้า Landing จริง
5. **CPM / CTR** — ตอนนี้เป็นกรอบอ้างอิงตลาด ไม่ใช่ข้อมูลจากบัญชีโฆษณาเรา

ป้าย `CONFIRMED` / `ESTIMATE` / `REQUIRES VALIDATION` ในหน้า Simulator บอกสถานะของทุกตัวอยู่แล้ว
